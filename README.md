# 🏨 Hotel Analysis Practice Dataset

## 📌 Project Overview

This project is a **self-created Hotel Analysis Practice Dataset** designed to practice and improve Data Analytics skills using real-world-style hotel booking and business data.

The dataset can be used to analyze hotel bookings, revenue, cancellations, room types, customer behavior, and overall hotel performance.

This project focuses on **data cleaning, exploratory data analysis, business insights, and data visualization**.

---

## 🎯 Project Objectives

The main objectives of this project are:

* Analyze hotel booking trends
* Identify revenue patterns
* Analyze room type performance
* Study booking cancellations
* Understand customer behavior
* Analyze monthly and yearly booking trends
* Identify high-performing hotel categories
* Calculate important business KPIs
* Generate meaningful insights from hotel data
